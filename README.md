# Моя аптечка — менеджер домашней аптечки и запасов

Локальное приложение для Windows на Python и Qt (PySide6). Помогает вести учёт
лекарств, медицинских товаров, бытовой химии и средств гигиены: следить за сроками
годности и остатками, получать уведомления и собирать список покупок. Все данные
хранятся в файле SQLite на вашем компьютере, интернет не нужен.

Учебный проект. Разработчик: Сергиенко А. С., группа ИСП-34.

## 1. Установка и запуск

### Что нужно

- Windows 10 или 11;
- Python 3.9 или новее (проект проверен на 3.14), скачать можно на
  https://www.python.org/downloads/ . При установке отметьте «Add python.exe to PATH».

Проверить, что Python установлен, можно командой `py --version` в PowerShell
(команда `py` ставится вместе с Python и работает, даже если `python` не найден).
Если вместо номера версии `python --version` выводит только слово «Python»
или ничего, это заглушка Microsoft Store: везде ниже пишите `py` вместо `python`.

### Шаг 1. Откройте папку проекта в PowerShell

```powershell
cd D:\aptechka
```

Подставьте путь к своей папке.

### Шаг 2. Создайте виртуальное окружение `.venv`

Виртуальное окружение — отдельная копия Python с библиотеками проекта. Она не
мешает другим программам и лежит прямо в папке проекта (около 300 МБ).

```powershell
py -m venv .venv
```

### Шаг 3. Установите библиотеки в `.venv`

Команды с полным путём к Python из `.venv` работают всегда, даже без активации:

```powershell
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Будут установлены `PySide6-Essentials` (интерфейс Qt) и `openpyxl` (файлы Excel).

**Необязательно: активировать окружение.** Тогда вместо `.venv\Scripts\python.exe`
достаточно писать `python`:

```powershell
.venv\Scripts\Activate.ps1
```

Признак активации: в начале строки появилось `(.venv)`. Если PowerShell отвечает, что
выполнение скриптов отключено, один раз выполните
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повторите активацию. Либо не
активируйте окружение вовсе и пользуйтесь полным путём.

### Шаг 4. Запустите программу

```powershell
.venv\Scripts\python.exe -m pharmacy
```

Откроется окно входа. Если вы запускаете впервые, нажмите «Зарегистрироваться» (см.
[раздел 2.2](#22-регистрация)). Папка `data` с базой `aptechka.db` создаётся сама.

### Шаг 5 (по желанию). Тестовый аккаунт со всеми данными

Чтобы сразу посмотреть программу в работе, создайте тестовый аккаунт с большим набором
данных (около 80 товаров, 85 позиций списка покупок, 50 уведомлений, 90 записей
истории):

```powershell
.venv\Scripts\python.exe -m pharmacy.db.seed --full
.venv\Scripts\python.exe -m pharmacy
```

Войдите: логин `nessquish`, пароль `demo12345`.

| Команда `python -m pharmacy.db.seed` | Что делает |
|---|---|
| *(без ключей)* | создаёт тестового пользователя с 8 товарами |
| `--full` | добавляет данные на все случаи: все состояния товаров, все виды истории и уведомлений, список покупок из всех источников |
| `--refill` | стирает данные тестового аккаунта и заполняет заново (другие аккаунты и база остаются) |
| `--reset` | удаляет весь файл базы (все аккаунты) и создаёт заново |
| `--bulk 1000` | добавляет 1000 товаров, чтобы проверить скорость |

Самый частый вариант: `--refill --full` (обновить тестовый аккаунт, не трогая остальные).

### Если что-то не запускается

| Проблема | Что делать |
|---|---|
| `python` ничего не выводит или пишет только «Python» | это заглушка Microsoft Store. Пишите `py` вместо `python` (`py -m venv .venv`). Либо отключите её: «Параметры» → «Приложения» → «Дополнительные параметры приложений» → «Псевдонимы выполнения приложений», выключите `python.exe` и `python3.exe` |
| после `py -m venv .venv` нет папки `.venv` | окружение не создалось: проверьте, что `py --version` показывает версию, и повторите. Не ставьте библиотеки командой `pip install` без окружения: они попадут в общий Python |
| `No module named PySide6` | вы запускаете не из `.venv`: используйте `.venv\Scripts\python.exe`, а не просто `python` |
| ошибка при установке библиотек | проверьте интернет и повторите шаг 3 |
| окно не открывается, ошибки не видно | смотрите файл `data\error.log` рядом с базой: в него пишется причина |
| нужно начать с чистого листа | закройте программу и удалите папку `data` (все данные пропадут) |

## 2. Руководство пользователя

### 2.1. Вход в программу

При запуске открывается окно входа. Слева описание программы, справа форма.

| Поле | Что вводить |
|---|---|
| **Логин / Эл. почта** | логин или адрес почты, который вы указали при регистрации (регистр не важен) |
| **Пароль** | ваш пароль. Значок «глаз» справа показывает или скрывает вводимые символы |
| **Запомнить это устройство 30 дней** | галочка: следующие 30 дней программа входит сама, без пароля |

Нажмите «Войти» или клавишу **Enter**. Ссылка «Зарегистрироваться» внизу открывает
регистрацию.

**Какие бывают ошибки**

- «Введите логин или эл. почту» и «Введите пароль»: поле пустое. Красная подсветка
  и сообщение появляются под нужным полем.
- «Аккаунт с таким логином или почтой не найден»: красным подсвечивается поле логина.
- «Неверный пароль»: красным подсвечивается только поле пароля, логин остаётся как есть.

**Запомнить устройство.** В файле хранится только номер пользователя, срок действия
и отпечаток хэша пароля, но не сам пароль. Запись перестаёт действовать, если вы
сменили пароль, вышли из аккаунта или прошло 30 дней. Не включайте галочку на чужом
компьютере.

**Тема и масштаб входа.** Окна входа и регистрации всегда следуют теме Windows (светлая
или тёмная) и не зависят от настроек аккаунта. Масштаб у них не меньше обычного (100%).

### 2.2. Регистрация

Нажмите «Зарегистрироваться» на экране входа. Заполните поля:

| Поле | Обязательно | Правила |
|---|---|---|
| **Имя пользователя** | нет | до 50 символов; если оставить пустым, будет равно логину |
| **Логин** | да | от 3 до 30 символов: латинские буквы, цифры, точка, дефис и подчёркивание. Логин должен быть уникальным |
| **Электронная почта** | да | в виде `имя@домен.ru` (латиница, цифры, `_ % + -`), до 100 символов. Одна почта на один аккаунт |
| **Пароль** | да | не короче 8 символов |
| **Повторите пароль** | да | должен совпасть с паролем |

Нажмите «Зарегистрироваться» или **Enter**. Если всё верно, вы сразу попадаете на
главную страницу.

Особенности:

- Логин и почта проверяются во время ввода. Пока вы печатаете первый раз, ошибки
  не показываются; они появляются, когда вы ушли с поля или нажали кнопку, и пропадают,
  как только значение исправлено.
- Кнопка «Зарегистрироваться» недоступна, пока в поле почты неверный адрес.
- «Этот логин уже занят» или «Эта почта уже зарегистрирована»: выберите другие.
- Пароль хранится в базе только в виде хэша (PBKDF2-SHA256 с солью), восстановить
  его нельзя. Если забыли пароль, придётся завести новый аккаунт.
- «Войти» внизу возвращает на экран входа.

### 2.3. Главное окно

После входа окно состоит из **бокового меню** слева и **рабочей области** справа.

**Боковое меню**

| Элемент | Что делает |
|---|---|
| Название «Моя аптечка» и кнопка-панель | кнопка сворачивает меню в узкую полосу; на полосе кнопка разворачивает обратно |
| **Поиск** | открывает поиск по программе (то же, что **Ctrl+F**), см. [2.9](#29-поиск-по-программе) |
| **Главная**, **Моя аптечка**, **Список покупок**, **Уведомления**, **История**, **Настройки** | переход между разделами. У «Уведомлений» справа число непрочитанных |
| Аватар и имя внизу | нажатие открывает «Настройки», раздел «Аккаунт» |
| **Тёмная тема / Светлая тема** | быстро переключает тему |
| **Выход** | выйти из аккаунта (после подтверждения) |

Меню не прячется само: сворачиваете и разворачиваете его только вы, выбор запоминается.

**Окно.** Размер можно менять; минимальная ширина около 800 пикселей, при крупном
шрифте она больше. Когда окно узкое, кнопки и фильтры в шапке страницы переходят на
вторую строку. Длинные тексты обрезаются многоточием, таблицы подстраивают число строк
под высоту окна.

**Диалоги.** Окна подтверждения, формы и выпадающие списки открываются поверх основного
окна, а не отдельными окнами. **Esc** закрывает диалог или список, **Enter** подтверждает.

### 2.4. Главная

Сводка по аптечке на сегодня.

- **Приветствие** зависит от времени на вашем компьютере: утро с 5:00, день с 12:00,
  вечер с 18:00, ночь с 23:00. Справа кнопка «Добавить товар в аптечку».
- **Четыре карточки-счётчика** (нажимаются): «Товаров в аптечке» (открывает «Мою
  аптечку»), «Требуют внимания» (открывает «Уведомления»), «Просрочено» (аптечка с
  фильтром «Просрочен»), «В списке покупок» (список покупок, вкладка «Не куплено»).
- **Требуют внимания**: до пяти самых срочных товаров (просроченные, потом скоро
  истекающие, потом с низким остатком) с пояснением и кнопкой «В список» (добавить в
  список покупок). Если товар уже в списке, кнопка «В списке» неактивна. Ссылка «Все
  уведомления» ведёт в раздел уведомлений.
- **Последние добавленные**: пять товаров с категорией и датой добавления. Ссылка
  «Вся аптечка» открывает таблицу. Название товара везде открывает его карточку.

### 2.5. Моя аптечка

Таблица всех ваших товаров. Столбцы: **Название**, **Дата добавления**, **Категория**,
**Количество**, **Ед. изм.**, **Срок годности**, **Место хранения**, **Состояние**.

**Состояние товара** считается само:

| Состояние | Когда |
|---|---|
| Просрочен | срок годности раньше сегодняшней даты |
| Скоро истекает | до конца срока осталось не больше N дней (N в настройках, по умолчанию 30) |
| Низкий остаток | количество не больше минимального остатка товара (или порога из настроек) |
| Норма | ни одно условие не выполнено |

Если условий несколько, в таблице показывается важнейшее: просрочен, затем скоро
истекает, затем низкий остаток; в карточке товара видны все.

**Верхняя панель**

- **Добавить товар в аптечку**: открывает форму (см. [2.6](#26-карточка-добавление-и-редактирование-товара)).
- **Поиск по названию**: ищет по мере ввода, с небольшой задержкой. Регистр, буква
  «ё» и окончания слов не мешают: по «витамины» найдётся «Витамин D».
- **Категория**: «Все категории» или одна из четырёх.
- **Состояние**: «Любое состояние» или одно из четырёх.
- **Сортировка**: выберите вид (по состоянию, названию, количеству, сроку годности,
  категории, месту хранения, дате добавления), затем направление (например, «от А до
  Я» или «от Я до А»). Выбор запоминается для вашего аккаунта. По умолчанию товары
  идут по состоянию: сверху просроченные.

**Сортировка нажатием на заголовок.** Нажмите на заголовок столбца (кроме «Ед. изм.»):
таблица отсортируется по нему. Повторное нажатие меняет направление. Рядом с заголовком
фиолетовой надписью показывается текущее направление («А-Я», «9-0», «ближе» и т. п.).

**Выбор строк и массовые действия.** Слева у каждой строки есть флажок; нажатие на
свободное место строки тоже отмечает её. Флажок в шапке отмечает все товары страницы.
Как только что-то отмечено, над таблицей появляется панель «Выбрано: N»:

| Кнопка | Что делает |
|---|---|
| **Снять выбор** | снимает все отметки |
| **Выбрать все** | отмечает все товары, подходящие под поиск и фильтры, на всех страницах |
| **Сменить категорию** | переносит отмеченные в выбранную категорию |
| **В список покупок** | добавляет по одной единице каждого; если товар уже в списке, его количество растёт |
| **Удалить выбранные** | удаляет после подтверждения (действие нельзя отменить) |

После действия на несколько секунд показывается итог («Удалено товаров: 3»).

**Страницы.** Внизу слева написано «Показано 1–8 из 82», справа переключатель страниц:
не больше пяти номеров, текущая стоит посередине, стрелки листают на одну страницу.
Число строк на странице подгоняется под высоту окна.

Если в аптечке ещё нет товаров, показывается приглашение «Добавить товар в аптечку».

### 2.6. Карточка, добавление и редактирование товара

**Карточка.** Нажмите на название товара где угодно (таблица, главная, уведомления,
список покупок): откроется окно с подробностями. В заголовке название, категория, дата
добавления и плашки всех состояний. Ниже: количество, минимальный остаток, срок годности
(с пояснением «через 19 дней» или «просрочено на 3 дня»), место хранения, показания и
примечание. Внизу кнопки:

- **Удалить**: удаляет товар после подтверждения. Уведомления о нём удаляются, а в
  истории запись остаётся.
- **В список покупок** (или **Добавить ещё в список**, если товар уже в списке):
  добавляет единицу в список покупок.
- **Редактировать**: открывает форму.

Показания вносит сам пользователь, это не медицинская рекомендация.

**Форма добавления и редактирования**

| Поле | Обязательно | Правила |
|---|---|---|
| **Название** | да | до 100 символов |
| **Категория** | да | Лекарства, Медицинские товары, Бытовая химия, Средства гигиены |
| **Количество** | да | число от 0 до 1 000 000; дробное через запятую или точку (1,5) |
| **Единица измерения** | да | шт., упак., табл., мг, г, мл, фл. (по умолчанию шт.). Выбранная единица пишется в подписях «Количество» и «Минимальный остаток» |
| **Срок годности** | нет | ДД.ММ.ГГГГ, например 31.12.2027; пустое поле означает, что срока нет |
| **Дата добавления** | — | показывается, ставится сама и не редактируется |
| **Место хранения** | нет | до 100 символов, например «шкаф» |
| **Минимальный остаток** | нет | число; ниже этого количества товар считается «Низкий остаток» (пусто = 0) |
| **Показания / назначение** | нет | до 500 символов |
| **Примечание** | нет | до 500 символов |

Красная звёздочка у подписи означает обязательное поле. Ошибки показываются красным
под полем, кнопка «Сохранить» неактивна, пока ошибка не исправлена. После сохранения
нового товара открывается «Моя аптечка», нужная страница и строка подсвечивается на
несколько секунд. Все изменения записываются в историю («количество изменено с 5 до
10» и т. п.).

### 2.7. Список покупок

Что нужно купить. Три вкладки с числами: **Все**, **Не куплено**, **Куплено**.
Столбцы: **Товар**, **Дата добавления**, **Количество**, **Источник**, **Статус**.

- **Товар** со ссылкой на карточку (если позиция создана по товару аптечки и не куплена)
  открывает карточку. Купленные позиции зачёркнуты.
- **Источник** показывает, откуда позиция: «Вручную», «Уведомление», «Моя аптечка»,
  «Карточка товара», «Главная», «Импортировано» (из файла Excel).
- **Добавить вручную**: окно с полями «Название товара», «Количество» (по умолчанию 1,
  больше нуля) и «Единица измерения». Пока вы печатаете название, ниже появляются
  подходящие товары аптечки (с количеством в аптечке): выберите, и у позиции будет ссылка
  на карточку. Стрелка в поле открывает все товары аптечки.
- Если товар уже есть в списке и не куплен, повторное добавление увеличивает количество,
  а не создаёт вторую позицию. Из уведомления о низком остатке количество рассчитывается
  до двойного минимального остатка.

**Выбор строк**: флажки, «Выбрать все», «Снять выбор», как в аптечке. Кнопки панели:
**Отметить как купленные** (если все выбранные уже куплены, кнопка превращается в
**Вернуть в список**) и **Удалить из списка**. Покупка и удаление записываются в историю.
Остаток в аптечке при покупке сам не меняется: после покупки обновите количество в форме
товара.

Внизу то же листание по страницам, что и в аптечке.

### 2.8. Уведомления

Список предупреждений о товарах. Они не копятся, а **пересчитываются** из состояния
товаров: при входе, при добавлении и изменении товара и при смене настроек.

- Причина появилась: создаётся непрочитанное уведомление.
- Изменился текст (например, остаток): он обновляется, отметка «прочитано» остаётся.
- Причина исчезла (срок продлён, запас пополнен, товар удалён): уведомление
  исчезает.
- Вручную удалённое уведомление вернётся, если причина не устранена.

Виды: «Срок годности истёк», «Скоро истекает срок годности», «Низкий остаток».
У непрочитанных слева точка и цветная подложка.

**Верхняя панель**: фильтр периода («За всё время», «Сегодня», «Последние 7 дней»,
«Последние 30 дней»), кнопка **Прочитать все** и красная кнопка **Очистить
уведомления** (с подтверждением; пока уведомлений нет, неактивна).

**Вкладки**: «Все», «Непрочитанные», «Срок годности», «Низкий остаток» (с числами).
Справа подсказка о том, за сколько дней идёт предупреждение (меняется в настройках).

**В каждой строке**: значок, вид и текст, время («сегодня, 09:00» или дата), кнопки
**Открыть товар** (открывает карточку и отмечает уведомление прочитанным) и
**В список покупок** (если товар уже в списке, вместо кнопки плашка «В списке покупок»),
а справа крестик, который удаляет уведомление. Список листается внутри карточки,
шапка остаётся на месте.

### 2.9. Поиск по программе

Откройте нажатием на «Поиск» в меню или клавишами **Ctrl+F** (работает и на русской
раскладке). Вводите текст, результаты появляются по мере набора и разбиты на группы:

- **Моя аптечка**: товары (по названию, категории и примечанию), переход открывает
  таблицу на нужной странице с подсвеченной строкой;
- **Карточка товара**: открыть карточку сразу;
- **Список покупок**, **Уведомления**: найденные позиции;
- **История**: записи с этим текстом (открывает историю за всё время с поиском);
- **Разделы и настройки**: любой раздел меню или настройка (например, «тёмная», «масштаб»,
  «экспорт»).

Стрелки вверх и вниз двигают выбор, **Enter** открывает верхний результат, **Esc** или
крестик закрывают окно.

### 2.10. История

Журнал ваших действий по дням («Сегодня, 13.10.2026», затем прошлые даты). Записи
создаются сами: добавление, изменение и удаление товара, добавление в список покупок,
покупка, удаление из списка.

- **Поиск по товару**: фильтрует записи по тексту описания.
- **Все действия**: фильтр по виду действия.
- **Период**: по умолчанию «Последние 7 дней»; есть «Сегодня», «30 дней», «За всё время».
- **Очистить историю**: после подтверждения удаляет все записи (товары и список покупок
  не меняются). Кнопка неактивна, если истории нет.
- Показывается не больше 300 последних записей по выбранным условиям.

### 2.11. Настройки

Слева список разделов, справа содержимое выбранного. Большинство настроек применяются
сразу, плашка «Изменения сохранены» появляется вверху.

**Внешний вид**

- **Тема**: «Светлая», «Тёмная» или «Системная» (повторяет тему Windows и меняется
  вместе с ней). Тема общая для всех аккаунтов на этом компьютере.
- **Масштаб**: «Авто» подбирает размер по разрешению и плотности пикселей экрана;
  «Ручной» даёт ползунок от 80% до 150%. Масштаб меняется только при запуске, поэтому
  программа предлагает **перезапустить** (если устройство не запомнено, войти нужно
  заново). Окна входа и регистрации от этой настройки не зависят: они идут в своём
  масштабе, а ваш ручной действует после входа.
- **Размер шрифта**: «Мелкий», «Средний», «Крупный». Окно и меню расширяются вместе с
  текстом.
- **Значки в меню**: показывать ли значки рядом с названиями разделов.
- **Акцентный цвет**: пока отмечен «Скоро».

**Уведомления**

- **Включить уведомления**: общий выключатель.
- **Срок годности истёк**: напоминать о просроченных товарах.
- **Скоро истекает срок**: за сколько дней предупреждать (от 1 до 30, по умолчанию 30)
  и включатель.
- **Низкий остаток**: порог «меньше N шт.» и включатель. Если оставить 0, остаток
  сравнивается с минимальным остатком самого товара.

**Данные**

- **Экспорт данных**: все товары в файл **CSV** (разделитель `;`, открывается в Excel)
  или **Excel**.
- **Импорт данных**: добавляет товары из файла CSV или Excel (см. ниже).
- **Шаблон для импорта**: готовый файл для заполнения (Excel с двумя таблицами или
  простой CSV).
- **Очистить историю** и **Сбросить все данные** (аптечка, список покупок, история и
  уведомления; аккаунт остаётся). Оба действия с подтверждением и без возможности отмены.

**Аккаунт**

- **Имя пользователя**, **Логин**, **Электронная почта**: у каждого кнопка «Изменить»,
  открывающая своё окно. Правила те же, что при регистрации.
- **Пароль → Сменить пароль**: текущий, новый и повтор нового. После смены запись
  «запомнить устройство» сбрасывается.
- **Выйти из аккаунта**: с подтверждением.
- **Удалить аккаунт**: вместе со всеми данными, **навсегда**. Просит подтвердить дважды.

**О программе**: название, версия, дата сборки, разработчик и кнопка «Открыть» (страница
проекта на GitHub).

### 2.12. Импорт данных из Excel и CSV

**Через шаблон Excel (рекомендуется)**

1. «Настройки» → «Данные» → «Шаблон для импорта» → **Excel**, выберите, куда сохранить.
2. Откройте файл. В нём три листа:
   - **Правила**: как заполнять и какие бывают ошибки;
   - **Моя аптечка**: Название, Категория, Количество, Ед.изм., Срок годности, Место
     хранения;
   - **Список покупок**: Товар, Количество.
3. Заполняйте строки подряд, без пропусков. Рамки и цвет продолжаются сами. Категорию и
   единицу выбирайте из выпадающего списка в ячейке. Срок годности вводите как
   `ДД.ММ.ГГГГ`.
4. Сохраните файл и выберите «Импорт данных» → **Excel** (или **CSV**), укажите файл.

Листы и заголовки столбцов переименовывать нельзя: по ним программа находит данные.

**Что обязательно**

- Для аптечки: Название (до 100 символов), Категория (одна из четырёх), Количество
  (число от 0 до 1 000 000).
- Для списка покупок: Товар (до 100 символов); количество больше 0, пусто означает 1.
  Такие позиции получают источник «Импортировано».

**Итог импорта** показывается в окне:

```
Добавлено товаров в аптечку: 3
Добавлено товаров в список покупок: 67
Ошибка импорта: Слишком большое значение (Моя аптечка, строки 3, 5)
```

Строка с ошибкой пропускается, остальные добавляются. Причина указана для каждой такой
строки: лист и номер строки в вашем файле. Исправьте её и импортируйте только эти строки
(остальные уже добавлены, иначе будут дубли).

Файлы CSV и Excel, сохранённые экспортом программы, тоже читаются: товары берутся с
первого листа.

### 2.14. Где хранятся данные и как сделать копию

| Как запущена программа | Где лежат данные |
|---|---|
| из исходников (`python -m pharmacy`) | папка `data` в папке проекта |
| собранный `Aptechka.exe` | `%LOCALAPPDATA%\Моя аптечка\data` |

В папке:

- `aptechka.db` — база (аккаунты, товары, покупки, история, уведомления);
- `preferences.json` — настройки вида (тема, масштаб, размер шрифта, сортировка, порог
  остатка);
- `remember.json` — запись «запомнить устройство»;
- `error.log` — журнал ошибок, если программа аварийно остановилась.

**Копия данных**: закройте программу и скопируйте `aptechka.db` (и `preferences.json`) в
безопасное место. Чтобы восстановить, закройте программу и верните файлы на место.
Другая база задаётся переменной окружения `APTECHKA_DB` (путь к файлу).

### 2.15. Частые вопросы

- **Почему уведомление вернулось после удаления?** Уведомления строятся из состояния
  товаров. Пока срок не продлён или запас не пополнен, оно будет появляться снова.
- **Почему при покупке не изменился остаток?** Список покупок только отмечает покупку.
  Количество в аптечке вы меняете сами в форме товара.
- **Почему при входе или выходе программа перезапускается?** Так бывает, если выбран
  ручной масштаб: масштаб Qt меняется только при запуске. Окна входа идут в своём
  масштабе, ваш применяется после входа.
- **Как перенести данные на другой компьютер?** Скопируйте папку `data` (см. 2.14), либо
  экспортируйте товары в Excel и импортируйте на другом компьютере.
- **Как вернуться к данным «с чистого листа»?** «Настройки» → «Данные» → «Сбросить все
  данные».

## 3. Сборка программы в .exe

Собирается один файл `dist/Aptechka.exe` (около 50 МБ). Python на другом компьютере не
нужен.

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe packaging\build_exe.py
```

С ключом `--demo` собирается `dist/Aptechka-Demo.exe` с готовым тестовым аккаунтом
`nessquish` (пароль `demo12345`); его данные лежат отдельно в
`%LOCALAPPDATA%\Моя аптечка (демо)`.

- Файл достаточно скопировать на другой компьютер с Windows 10 или 11 и запустить. Установщик не нужен.
- Данные хранятся в `%LOCALAPPDATA%\Моя аптечка\data` и не пропадают при замене `.exe`.
- На новом компьютере база пустая: сначала нужно зарегистрироваться.
- Windows SmartScreen может предупредить о «неизвестном издателе», потому что файл
  не подписан. Нажмите «Подробнее» и «Выполнить в любом случае».
- Если программа не запустилась, причина записана в `error.log` рядом с базой.

### Структура проекта

Слои соответствуют разделу 2 ТЗ (многослойная архитектура), зависимости идут сверху вниз.

| Папка | Назначение |
|---|---|
| `pharmacy/db/` | схема SQLite, менеджер базы (Database Manager), тестовые данные (`seed.py`, `seed_data.py`) |
| `pharmacy/models.py` | модели данных: пользователь, товар, категория, уведомление, список покупок, история |
| `pharmacy/errors.py` | ошибки с сообщениями для пользователя |
| `pharmacy/utils/` | хэширование паролей, проверка ввода, даты, единицы, мягкий поиск по тексту |
| `pharmacy/repositories/` | запросы к таблицам (Repository), только SQL |
| `pharmacy/services/` | бизнес-логика (Service Layer): вход, товары, состояние, уведомления, список покупок, история, настройки, сводка, экспорт и импорт |
| `pharmacy/ui/` | интерфейс на Qt по макету Figma: тема, шрифт Inter, виджеты, экраны |
| `pharmacy/assets/` | шаблон Excel для импорта |
| `packaging/` | сборка `.exe` (PyInstaller) |
| `tests/` | автоматические тесты (`unittest`) |

### Как устроен интерфейс

Интерфейс нарисован только кодом, без картинок макета: окно собирается и рисуется
целиком и показывается готовым кадром, поэтому при смене разделов нет мерцания.

- `theme.py` хранит палитры (светлая из макета, тёмная подобрана к ней), размеры и стили
  текста; `paint.py` рисует скруглённые фигуры и тени; `icons.py` собирает иконки Lucide
  из контуров (SVG); `fonts.py` подключает шрифт Inter из `assets/fonts` (лицензия SIL OFL).
- `widgets/` — кнопка, поле ввода, плашка, карточка, таблица, выпадающий список, диалоги.
  Выпадающие списки и диалоги лежат внутри главного окна, а не открываются отдельными окнами.
- Экраны (`screens/`) обращаются только к сервисам из `services/container.py`, не к базе.
- Палитра и размер текста читаются при создании виджетов, поэтому смена темы, размера
  текста или значков перестраивает окно целиком.
- Масштаб (`scaling.py`) задаётся до создания `QApplication` и на лету не меняется.
- Настройки внешнего вида хранятся в JSON рядом с базой, схема базы остаётся по ER-диаграмме.

### Соответствие ER-диаграмме

В ER-диаграмме ТЗ имена русские, в коде английские.

| ER-диаграмма | Таблица | Основные поля |
|---|---|---|
| Пользователи | `users` | `login`, `username`, `email`, `password_hash`, `warning_days`, `theme`, `notify_expired`, `notify_low_stock`, `created_at` |
| Категории | `categories` | `name` |
| Товары | `products` | `user_id`, `category_id`, `name`, `quantity`, `unit`, `expiry_date`, `indications`, `storage_place`, `min_quantity`, `note`, `created_at` |
| Уведомления | `notifications` | `user_id`, `product_id`, `kind`, `message`, `is_read`, `created_at` |
| Список покупок | `shopping_list` | `user_id`, `product_id`, `name`, `quantity`, `unit`, `source`, `is_bought`, `created_at` |
| История | `history` | `user_id`, `product_id`, `action`, `description`, `created_at` |

Правила удаления: при удалении пользователя все его данные удаляются каскадно. При
удалении товара его уведомления удаляются, а в истории и списке покупок ссылка на товар
обнуляется (`ON DELETE SET NULL`), сами записи остаются.

и вливается в `main` через Pull Request после ревью.
