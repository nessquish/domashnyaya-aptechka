Функциональность
================

* Регистрация и вход по логину или электронной почте, запоминание устройства,
  смена пароля, удаление аккаунта. Пароли хранятся как хэш PBKDF2-HMAC-SHA256
  со случайной солью.
* Учёт товаров: название, категория, количество и единица, срок годности,
  показания, место хранения, минимальный остаток, примечание.
* Поиск, фильтры по категории и состоянию, сортировка, массовые действия.
* Состояние товара вычисляется (просрочен, скоро истекает, низкий остаток,
  норма) и в базе не хранится.
* Уведомления пересчитываются из состояния товаров при входе, изменении товара
  и смене настроек.
* Список покупок: добавление вручную, из аптечки, из уведомления; отметка «куплено».
* История действий с фильтрами и очисткой.
* Настройки: тема (светлая, тёмная, системная), масштаб, размер текста,
  срок предупреждения, порог низкого остатка.
* Экспорт и импорт CSV и Excel с шаблоном; поиск по программе (Ctrl+F).

Пример использования сервисного слоя
------------------------------------

.. code-block:: python

   from pharmacy.db.connection import Database
   from pharmacy.services.container import build_services

   db = Database("data/aptechka.db")
   db.init_schema()
   services = build_services(db)
   user = services.auth.register(
       "anna", "Анна", "anna@mail.ru", "password1", "password1"
   )
   items = services.products.list_products(user.id, search="ибу")
