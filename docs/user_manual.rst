Руководство пользователя
========================

Запуск
------

Готовая программа: запустите ``domashnyaya-aptechka.exe`` (чистая версия) или
``domashnyaya-aptechka-demo.exe`` (демонстрационная версия с тестовым
аккаунтом). Python устанавливать не нужно. Данные хранятся в
``%LOCALAPPDATA%\Моя аптечка\data``.

Из исходного кода:

.. code-block:: text

   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   .venv\Scripts\python.exe -m pharmacy

Основные действия
-----------------

1. Зарегистрируйтесь или войдите (логин или электронная почта и пароль).
2. В разделе «Моя аптечка» нажмите «Добавить товар в аптечку» и заполните форму.
3. На главной и в «Уведомлениях» видны товары с истекающим сроком и низким остатком;
   кнопка «В список» добавляет товар в список покупок.
4. «Настройки» → «Данные»: экспорт, импорт, шаблон Excel, сброс.
5. Ctrl+F: поиск по товарам, спискам, истории и настройкам.

Устранение проблем
------------------

* Вместо Python открывается Microsoft Store: отключите заглушку в параметрах
  «Псевдонимы выполнения приложения» или установите Python.
* Не найден модуль ``pharmacy`` или ``PySide6``: запускайте из корня проекта и
  установите зависимости в ``.venv``.
* PowerShell запрещает скрипты: вызывайте ``.venv\Scripts\python.exe`` напрямую.
* SmartScreen предупреждает о неподписанном файле: «Подробнее» → «Выполнить в любом случае».
* Окно не открывается: причина записана в ``error.log`` в папке данных.
* Файл экспорта не сохраняется: закройте его в Excel и сохраните снова.
